# **App Name**: VeriTakip

## Core Features:

- Dashboard Analytics: Provide a real-time overview of personnel attendance, including total staff, active employees, latecomers, weekly attendance rates, entry/exit flow, and branch-specific summaries with interactive graphs.
- Personnel Management: Comprehensive tools to manage employee profiles, departments, positions, branches, security roles, QR IDs, device IDs, work types, and active/inactive statuses within the organization.
- Shift Management: Plan, create, and assign weekly shifts using a calendar view, manage shift change requests, and configure alerts for early departures or late arrivals.
- Attendance Record Viewer: Access and review detailed attendance logs for each employee, capturing QR-based and face-verified entries, including GPS data for remote or field work.
- Role-Based Access Control: Administer granular permissions for Super Admins, HR personnel, Branch Managers, and other roles to control access and actions within the system based on their responsibilities.
- Reporting and Export: Generate and export essential reports in PDF and Excel formats, covering personnel attendance, branch-wise summaries, overtime, and absenteeism analyses.
- Intelligent Attendance Anomaly Detection Tool: An AI-powered tool that analyzes real-time and historical attendance data to proactively identify unusual patterns or potential discrepancies, flagging them for HR review and offering actionable insights.

## Style Guidelines:

- Primary Color: A deep, professional navy blue (#0E2B4D) to establish a corporate and premium brand identity.
- Main Background: Clean white (#FFFFFF) for primary content areas and a very light grey (#F8F8F8) for secondary backgrounds and structural elements, aligning with a professional, light theme.
- Accent Color: A strong, corporate red (#CC0000) for highlighting interactive elements, call-to-actions, and critical information, ensuring clear visual focus.
- Status Colors: Utilize a consistent palette with black for 'Pending' (#000000) and a strong red for 'Critical' (#CC2626) statuses.
- Primary Font: 'Inter' (sans-serif) for both headlines and body text, providing a modern, clean, and highly readable typeface suitable for data-rich corporate applications.
- Implement a corporate and minimalistic icon system. Icons should be clear, professional, and visually consistent with the overall SaaS aesthetic.
- Adopt a clean and spacious layout featuring a prominent left sidebar for navigation, a functional topbar, and modular dashboard cards with ample whitespace to ensure a premium feel and easy readability. The design will be fully responsive across devices.
- Incorporate subtle and smooth animations for interactive elements, such as gentle hover effects, professional transitions in the left menu, and soft data update animations, to enhance user experience without distraction.
